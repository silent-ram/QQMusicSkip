# QQ Music Skip

一个 Android QQ 音乐辅助工具，可从系统通知和 MediaSession 识别当前歌曲，并根据用户规则自动跳过指定歌曲。

> 项目处于早期开发阶段。QQ 音乐通知字段及非公开接口可能随版本变化，请勿将识别结果用于付费或版权判断。

## 功能

- 识别歌曲名、歌手、专辑、封面、播放进度和当前歌词
- 免费、VIP、全部保留三种默认策略
- 单曲“自动 / 保留 / 跳过”规则，优先于全局策略
- 历史歌曲搜索及付费状态、规则筛选
- 诊断日志搜索、复制、分享和文本文件导出
- 通知监听断线检测及自动恢复
- 上一首、播放/暂停、下一首媒体控制

## 环境要求

- Android 8.0（API 26）及以上
- Android Studio 或 JDK 17
- QQ 音乐通知读取权限
- 查询付费状态和在线歌词时需要网络连接

## 构建

```bash
git clone https://github.com/silent-ram/QQMusicSkip.git
cd QQMusicSkip
./gradlew assembleDebug
```

Windows：

```powershell
.\gradlew.bat assembleDebug
```

APK 输出位置：

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 使用

1. 安装并打开应用。
2. 进入“设置”，授权通知读取权限。
3. 打开 QQ 音乐并播放歌曲。
4. 在“播放”页确认监听状态和识别结果。
5. 在“历史”页为歌曲设置保留或跳过规则。

如果显示“已授权，但监听服务尚未连接”，可点击设置页的“重启监听”。部分 vivo 等厂商系统还需要允许应用后台运行。

## 默认规则

规则优先级：

```text
自动跳过关闭
> 单曲手动保留/跳过
> 全局默认策略
> 查询失败或未知时保守保留
```

默认配置为：自动跳过免费歌曲，VIP 和未知歌曲保留。

## 隐私

- 应用只处理 QQ 音乐通知。
- 歌曲历史、设置和诊断日志保存在设备本地。
- 应用不会上传通知内容或诊断日志。
- 用户主动使用系统分享或导出功能时，数据才会离开应用。

## 已知限制

- 通知监听服务由 Android 系统管理，部分厂商系统可能延迟或中断绑定。
- QQ 音乐没有提供 MediaSession 字段时，封面、进度或歌词可能为空。
- 付费状态和在线歌词依赖 QQ 音乐接口，接口变化或网络异常时会返回未知并保守保留。
- 当前单元测试覆盖仍有限，提交规则或通知解析改动时应补充测试。
